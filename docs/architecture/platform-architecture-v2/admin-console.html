Admin console

Internal staff surface with zero standing access to any company's data. Support happens through a break-glass session: reason required, time-boxed, and written to the audit log before the first read. Cross-tenant views show only aggregate, non-PII health. (UI mocked in v1.)

Principle default-deny into tenant data; every view here is itself audited Diagrams conceptual · component · sequence · communication · data-flow
